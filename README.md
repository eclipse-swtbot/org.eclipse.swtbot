# SWTBot

SWTBot is a Java API that interacts with SWT by using high-level operations.
It is generally used to write UI tests efficiently since the grain of the API is the same grain as UI operation.
It makes it easier to transform a user scenario into automated tests.

* https://projects.eclipse.org/projects/technology.swtbot
